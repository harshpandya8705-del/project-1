Personal Data Collector

Overview

The Personal Data Collector is a beginner-friendly Python project that collects user data and provides simple analysis.

Features

• Collects user input (name, age, height, favourite number)

• Identifies Adult or Minor

• Checks Even or Odd number

• Calculates approximate birth year

Technologies Used

Python (Basic Concepts)

How to Run

1. Install Python 2. Run: python main.py

Concepts Used

• Input/Output

• Type casting

• Conditional statements

• Operators

String methods
